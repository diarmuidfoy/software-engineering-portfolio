# software-engineering-portfolio
ATU Semester 7 software engineering repository

Diarmuid Foy L00160781
In this module, I expect to learn why software engineering emerged as a discipline and understand the “software crisis” that highlighted the need for more structured and reliable approaches to developing software. 
I also expect to learn how software engineering is defined and how it differs from computer science and simply programming. 
Furthermore, I want to understand the key characteristics of software engineering and why serious software failures can still occur today. 
Finally, I expect to learn the difference between a software process and a software product, as well as the four fundamental activities involved in the software development process.
